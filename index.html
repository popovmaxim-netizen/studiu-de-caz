Noțiuni de bază

Ce sunt Git și GitHub?

Git și GitHub au roluri diferite, dar sunt folosite împreună pentru dezvoltarea și organizarea proiectelor.

Criteriu Git GitHub
Definiție Sistem distribuit pentru controlul versiunilor. Platformă online pentru găzduirea proiectelor Git.
Locul utilizării Este utilizat local, pe calculator. Este utilizat online, printr-un repository.
Rol principal Salvează istoricul modificărilor prin commit-uri. Permite colaborarea între membrii echipei.
Instrumente Commit, branch, merge, push și pull. Repository, Issues, Projects și Pull Requests.
Importanță

Avantajele utilizării Git și GitHub

Aceste instrumente ajută echipa să lucreze organizat, sigur și eficient la același proiect.

🕒

Istoricul modificărilor

Fiecare commit arată ce a fost schimbat, cine a efectuat modificarea și când a fost realizată.

🤝

Colaborare

Mai mulți membri pot lucra în același timp pe diferite părți ale proiectului.

🛡️

Siguranță

Versiunile anterioare pot fi recuperate atunci când apare o greșeală în proiect.

🔍

Verificarea codului

Pull request-urile permit verificarea codului înainte ca acesta să fie integrat.

📋

Organizarea sarcinilor

GitHub Issues și Projects ajută la repartizarea și urmărirea sarcinilor.

🌐

Acces de oriunde

Proiectul poate fi accesat de membrii echipei de pe calculatoare diferite.

Flux de lucru

Cum lucrează echipa?

Respectarea unui proces clar reduce conflictele și face contribuțiile ușor de verificat.

Crearea repository-ului

Coordonatorul creează repository-ul pe GitHub și adaugă membrii echipei.

Clonarea proiectului

Fiecare membru clonează proiectul pe propriul calculator folosind comanda git clone.

Crearea unui branch

Membrii creează branch-uri separate pentru sarcinile la care lucrează.

Salvarea modificărilor

Schimbările sunt salvate prin commit-uri care conțin mesaje clare.

Push și Pull Request

Codul este încărcat pe GitHub și verificat înainte de integrarea în branch-ul principal.

Merge și actualizare

După aprobare, schimbările sunt integrate, iar membrii descarcă versiunea actualizată.

CONCLUZIE

Un singur proiect, o echipă sincronizată

Git și GitHub sunt instrumente importante pentru realizarea unui proiect comun. Acestea permit păstrarea istoricului modificărilor, colaborarea dintre membrii echipei, verificarea codului și recuperarea versiunilor anterioare. Utilizate corect, ele reduc riscul pierderii fișierelor și contribuie la realizarea unui proiect organizat, sigur și eficient.
